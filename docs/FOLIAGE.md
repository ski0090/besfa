# 폴리지

지형 위에 풀처럼 아주 많이 깔리는 식물을 기른다. [bevy_foliage_tool](https://github.com/ethereumdegen/bevy_foliage_tool)(Bevy 0.16, 레이어마다 밀도 맵을 칠하고 청크마다 식물 엔티티를 만든다)을 참고했고, 밀도 맵 대신 지형의 겉면 레이어를 쓴다. 언리얼의 Landscape Grass Type과 같은 방식이다.

## 목표

- 폴리지는 `besfa_components`의 Reflect 컴포넌트 `besfa_editor_plugin::foliage::Foliage`다. 지형 엔티티나 그 아래 엔티티에 붙이고, 씬 파일에 저장되며, Inspector·되돌리기·`besfa_mcp`의 `set`이 그대로 통한다. 새 프로토콜 명령과 파일 형식은 없다.
- 식물은 지형의 겉면 레이어 하나가 덮은 만큼 자란다. 지형 붓의 `paint`로 풀 레이어를 칠하면 풀이 나고, 흙 레이어로 칠하면 사라진다.
- 식물 하나하나는 저장하지 않는다. 같은 지형과 같은 값이면 언제나 같은 자리에 자란다.
- 흩뿌리기(`Scattered`)와 나눠 쓴다. 베고 캐고 세이브에 남아야 하는 나무·바위·덤불은 흩뿌리기로 놓은 씬 엔티티이고, 폴리지는 하나하나 다룰 필요 없는 장식이다.

## 컴포넌트

```rust
pub struct Foliage {
    pub model: String,   // 에셋 폴더 기준 glTF 모델 (`props/grass-clump.glb`)
    pub layer: usize,    // 자라는 지형 겉면 레이어 0~3
    pub density: f32,    // 레이어가 땅을 다 덮은 곳의 1 m²당 식물 수 (기본 1, 64까지)
    pub scale: Vec2,     // 가장 작은·큰 크기 (기본 0.8~1.2)
    pub distance: f32,   // 카메라에서 이 m 안에서만 보인다 (기본 60, 마지막 5분의 1에서 흐려진다)
    pub shadows: bool,   // 그림자를 드리우는지 (기본 false)
}
```

`Foliage` 하나가 식물 한 종류다. 풀과 들꽃을 함께 기르려면 지형 아래에 엔티티를 둘 두고 각자 `Foliage`를 붙인다. Inspector의 컴포넌트 편집기가 구조체 목록은 고치지 못하므로 목록 필드를 두지 않았다. 모델 경로에 `#Scene0` 같은 라벨이 붙어 있으면 떼고 읽는다.

## 자라는 법

- 지형의 공간에 한 칸이 `1/√density` m인 격자를 깔고, 칸마다 식물 하나를 칸 안의 무작위 자리에 둔다. 칸의 수(칸 번호, 모델, 레이어의 해시)로 자리·회전·크기와 0~1의 수를 정하고, 그 수가 그 자리 레이어의 덮임(`TerrainData::cover`, 표본 사이는 섞는다)보다 작을 때만 기른다. 그래서 레이어를 조금씩 칠하면 식물도 같은 자리부터 조금씩 늘어난다.
- 높이는 그 자리 지형의 높이다. 땅의 기울기는 따르지 않는다.
- 지형을 16 m 정사각형으로 나눠 카메라(편집용·게임·스크린샷 카메라 모두)에서 `distance` 안에 드는 정사각형만 기르고, 멀어지면 버린다. 이미 있는 정사각형은 `distance`보다 16 m 더 멀어져야 버리므로 경계에서 깜빡이지 않는다.
- 정사각형은 맨 위 엔티티로 지형의 위치를 따르고, 그 자식인 식물은 모델의 메시마다 엔티티 하나다(`Mesh3d`, 모델의 `StandardMaterial`, `VisibilityRange`, 그림자를 끄면 `NotShadowCaster`). 같은 메시와 머티리얼이므로 Bevy가 인스턴스로 묶어 그린다. 모두 `EditorOnly`라 Hierarchy, 씬 파일, 붓과 클릭의 광선에서 빠진다.
- 지형 파일이 칠해져 바뀌면 보이는 정사각형마다 식물을 다시 셈해, 달라진 정사각형만 새로 기른다. `Foliage`나 `Terrain`이 바뀌어도 같고, 모델을 다시 읽으면 모두 새로 기른다. 숨기거나(`delete`) 지형에서 떼면 사라진다.

## 하지 않은 것

- 바람에 흔들리기: `StandardMaterial`을 확장하는 정점 셰이더가 필요하다. 풀숲을 실제로 깔 때 더한다.
- 따로 칠하는 밀도 맵: 땅 색과 상관없이 식물을 칠해야 할 때, `.terrain` 옆에 레이어별 밀도 파일을 두고 같은 기르는 코드에 넘긴다.
- 정사각형마다 식물을 하나의 인스턴스 버퍼로 그리기: 보이는 식물이 수십만 개를 넘어 엔티티 수가 느려질 때 커스텀 렌더 파이프라인으로 옮긴다.
