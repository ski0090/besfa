# 되돌리기

편집 상태에서 고친 것은 되돌리고(Undo) 다시 할(Redo) 수 있습니다.

## 쓰는 법

| 하는 일 | 메뉴 | 단축키 |
| --- | --- | --- |
| 되돌리기 | **Edit > Undo** | **Ctrl+Z** |
| 다시 하기 | **Edit > Redo** | **Ctrl+Y** 또는 **Ctrl+Shift+Z** |

글자 입력 칸에 커서가 있을 때 Ctrl+Z는 그 칸의 글자 되돌리기입니다. 씬 변경을 되돌리려면 칸 바깥을 한 번 누른 뒤 쓰세요.

## 되돌릴 수 있는 것

- Inspector에서 값 고치기
- 씬 뷰에서 핸들 끌기
- 컴포넌트 더하기와 빼기
- 엔티티 만들기, 복제, 삭제, 에셋을 씬에 놓기
- [땅에 내려놓기](04-scene-view.md#땅에-내려놓기)(한 번에 하나로)
- [지형](09-terrain.md) 칠하기(누른 뒤 뗄 때까지가 한 번)
- [흩뿌리기](10-scatter.md)(누른 뒤 뗄 때까지가 한 번)
- [Animation 탭](11-animation.md)에서 바꾼 것

## 되돌릴 수 없는 것

- **실행 상태에서 한 일.** 실행 중에는 Undo와 Redo가 꺼집니다. 실행 중의 변경은 Stop하면 어차피 사라집니다.
- **게임을 다시 시작하기 전의 일.** Stop, 플러그인 업데이트, 코드 변경으로 다시 빌드하면 되돌리기 기록이 모두 비워집니다.
- [모델 미리보기](08-model-preview.md) 패널에서 한 일. 미리보기 패널에는 따로 되돌리는 단추가 있습니다.
- 게임이 거절한 변경(예: 맞지 않는 값). 기록에 남지 않습니다.
- [Apply to prefab](07-assets-prefabs.md#프리팹-고치기)으로 프리팹 파일에 쓴 것.

새로 무언가를 고치면 다시 하기(Redo) 목록은 비워집니다.
